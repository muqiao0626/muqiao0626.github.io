Synthetic controller search

A completed exploratory comparison of bounded controller searches at 20 evaluations, with frozen-candidate results and explicit limits from one live search.

2026-10-16 · Updated 2026-10-24

Status: exploratory study complete

The research note compares bounded PID controller search using uniform random sampling, coordinate search, a scripted mock and one history-aware model run. Each search receives 20 candidate evaluations; a fixed reference receives one. The evaluator owns the objective and validation, and proposals contain data rather than executable code.

After development-only selection, the frozen live candidate achieved mean cost 0.092063 on the registered holdout cases, compared with 0.094983 for the mean of ten random searches and 0.094360 for coordinate search. Primary intervals favor that candidate but omit variation across live searches. The ten-repetition live confirmatory gate remains incomplete.

Inspect the evidence

The note includes reviewed figures, numeric results, per-seed holdout measurements and historical registrations. Research source code, raw model conversations and checkpoints are not part of this website release.

Local software verification covered controller bounds, anti-windup, scoring, strict proposals, duplicate rejection, budgets, split isolation and checkpoint resume. Two clean checkouts reproduced the mock results and both saved model-response streams. This checks deterministic software behavior, not model generation or general efficacy.

Smallest next experiment

Register multiple independent proposer searches and a new untouched evaluation split before running them. The original holdout is already inspected and must not be reused as untouched confirmation. The aim is to measure search-to-search variability before adding complexity to the research procedure.

Disclosure

Independent synthetic work with no employer code, data, designs or unpublished research. The result concerns one frozen candidate on known simulator regimes; general LLM-search superiority and recursive self-improvement are not established.
