Synthetic controller search

Specification complete; implementation planned — a bounded, synthetic test of hypothesis-guided search at matched evaluation budgets.

2026-10-16 · Updated 2026-10-17

Status: specification complete; experiments not run

The versioned benchmark specification is frozen locally. It defines the synthetic dynamics, controller bounds, objective, evaluation budget, and disjoint development and holdout seeds. The simulator and search methods remain to be implemented.

The question is whether a history-aware hypothesis proposer can select bounded controller variants that improve held-out cost more efficiently than non-LLM search given the same candidate-evaluation budget.

The intended task is finite-horizon setpoint tracking on a synthetic scalar plant. Candidates belong to a bounded PID-like family. The evaluator will own the objective, parameter validation, seeds, and development/holdout split; proposals will not contain executable code.

What would count as evidence?

A fixed reference, random search, and non-LLM local search will provide comparisons. Selection will use development data only. A frozen winner will be evaluated on untouched holdout data, with objective components, safety violations, paired uncertainty, and evaluation counts reported.

The first implementation will use a deterministic mock proposer offline. That run can validate the software pipeline; it cannot establish LLM effectiveness. A simpler baseline may perform better.

Smallest next step

Implement the deterministic simulator, controller, and scoring rules, and check them against hand-calculated examples using reserved test seeds. There are no measurements, code-release links, or performance claims to report yet.

Disclosure

Planned independent work. No experiments have been run, and LLM effectiveness has not been tested. No employer code, data, designs, or unpublished research are used.
