# Mu Qiao — personal website

A dependency-free, responsive personal site for `muqiao0626.github.io`.

## Preview

Run `python3 -m http.server 8000 --bind 127.0.0.1` from this directory, then visit http://127.0.0.1:8000.

## Publish on GitHub Pages

1. Create a public repository named **muqiao0626.github.io** under **muqiao0626**.
2. Upload this directory's files to its `main` branch, at the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. GitHub will publish the site at https://muqiao0626.github.io/.

Official instructions: https://docs.github.com/en/pages/quickstart

## Edit

- `index.html`: all visible content and links.
- `style.css`: layout, colors, and typography.
- `favicon.svg`: browser icon.
- Keep `.nojekyll` at the root for direct static publishing.

The writing section intentionally contains no invented essays. Replace its empty state with links to real writing when ready. Add a current biography, photo, CV, and preferred contact links when supplied by the owner.
